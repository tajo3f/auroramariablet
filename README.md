# Aurora Maria — Lifestyle V2

Landing page estática para **Aurora Maria Moreira Brandão**, 33 anos, com foco em uma apresentação lifestyle fora do universo pixel/Habblet.

## Conteúdo
- Hero editorial em tela cheia
- Apresentação da Aurora
- Seção lifestyle
- Galeria responsiva com lightbox
- Perfil editorial
- Aviso de personagem/modelo virtual para não confundir narrativa criativa com biografia real
- Responsividade mobile/tablet/desktop
- Imagens otimizadas em WebP
- Sem frameworks ou dependências externas

## Como abrir
1. Clique duas vezes em `ABRIR_SITE.bat` no Windows; ou
2. Abra `index.html` diretamente no navegador.

## Publicação
A pasta pode ser publicada diretamente em GitHub Pages, Netlify, Vercel ou Cloudflare Pages como site estático.
